## 🚀 À propos

**DevToolBox** est une suite d'outils web performants, gratuits et open-source, conçue pour simplifier les tâches quotidiennes des développeurs et professionnels IT. Tous les outils fonctionnent côté client pour garantir une confidentialité maximale.

- JSON Prettify & Minify
- XML Formatter
- SQL Prettify
- YAML Prettify
- TOML Formatter

## 🚀 Déploiement

Le projet est optimisé pour être déployé sur **Cloudflare Pages**, **GitHub Pages**, **Netlify**, ou **Vercel**.

### Installation locale

```sh
pnpm install
```

### Développement

```sh
pnpm dev
```

### Build pour la production

```sh
pnpm build
```

### Preview de la production

```sh
pnpm preview
```
