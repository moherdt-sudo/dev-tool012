## À propos

**DevToolBox** est une suite d'outils web performants, gratuits et open-source, conçue pour simplifier les tâches quotidiennes des développeurs. Tous les outils fonctionnent côté client pour garantir une confidentialité maximale.

## Fonctionnalités

- **Formatage & Minification** : JSON, XML, SQL, TOML, YAML.
- **Générateurs** : UUID, ULID, Tokens, Mots de passe, Lorem Ipsum.
- **Convertisseurs** : Base64, Date/Heure, Couleur, Case Converter.
- **Outils Réseau** : Analyseur d'URL, Calculateur de sous-réseau, Lookup MAC.
- **Sécurité** : Bcrypt, HMAC, Paire de clés RSA.

## Déploiement

Le projet est optimisé pour être déployé sur **Cloudflare Pages** ou **GitHub Pages**.

### Installation locale

```sh
pnpm install
```

### Développement

```sh
pnpm dev
```

### Build pour la production

```sh
pnpm build
```
